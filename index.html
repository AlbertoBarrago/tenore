One source.
Every agent.

tenore compiles a single .agents/ folder (Markdown + YAML) into the native instructions, permissions, MCP servers and memory of each AI coding agent. Switching agent becomes a 1:1 port.

The problem

Claude Code, Codex CLI, Gemini CLI and Antigravity each have their own format for the same ideas. You write your rules four times, they drift apart, and a permission tightened in one tool stays wide open in another.

How it works

.agents/
  AGENTS.md      # instructions
  policy.md      # permissions, mcp
  memory/*.md    # one topic per file
  local/         # gitignored

Three scopes merge deterministically: ~/.agents (global), <repo>/.agents, and .agents/local. Lists concatenate, narrower scalars win, and deny always wins.

Write it once

.agents/policy.md

---
permissions:
  default: ask
  allow:
    - shell: "npm run test*"
    - fs.write: "src/**"
  deny:
    - fs.read: ".env*"
    - network: none
mcp:
  github:
    command: npx
    args: [-y, "@mcp/github"]
    env:
      TOKEN: "${env:GITHUB_TOKEN}"
---

.claude/settings.json (permissions key only)

{
  "permissions": {
    "allow": [
      "Bash(npm run test*)",
      "Edit(src/**)"
    ],
    "deny": [
      "Read(.env*)",
      "WebFetch",
      "WebSearch"
    ]
  }
}

.mcp.json

"env": { "TOKEN": "${GITHUB_TOKEN}" }

Safe by construction

Never widens permissions

If a target cannot express a rule exactly, tenore picks the more restrictive option and tells you.

Secrets stay references

${env:VAR} is translated, never resolved into a generated file.

Drift detection

Generated files are hashed in .agents/.lock. Hand edits are reported, never overwritten.

Round-trip import

Import your existing CLAUDE.md and settings, sync, import again: same model.

Surgical merges

Shared JSON files are merged on owned keys only. Everything else you configured is left alone.

Atomic writes

Temp file plus rename. A crashed sync never leaves a half-written config.
